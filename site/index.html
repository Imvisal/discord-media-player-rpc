01 / Features

Everything you'd want, nothing to set up.

Automatic detection

Reads your player's window title and tells films from series episodes. Release noise like 1080p, x265 or site tags is cleaned up for you.

Posters and episode names

Artwork and episode titles come from TVmaze, AniList (anime), iTunes, IMDb and Wikipedia. A poster is only used when the title and year really match.

Genre and rating

The card can show the genre and the IMDb rating next to the title, like Comedy · ★ 7.4, when they can be found. You can turn it off in Settings.

Real progress bar

PotPlayer, VLC, MPC-HC and MPC-BE show a bar that follows seeking, pausing and resuming. Other players get an elapsed timer.

Films in your browser

Watching on a website? It's on by default: Media RPC reads the tab title of Chrome, Edge, Firefox, Brave, Opera and Vivaldi. Only a tab that is playing sound is looked at, and only a real film or series is shown. YouTube is a separate opt-in checkbox.

Pause detection

The card says "Paused" while the video is paused, or hides itself entirely if you prefer.

Settings that stay out of the way

Hide the status while paused, show or hide genre and rating, or switch on privacy mode so Discord only shows "Watching" your player and the file name is never looked up online.

One-click updates

Get notified when a new version is out and update in one click. Downloads are checked against a SHA-256 checksum before installing.

Works with the players you already use.

  • PotPotPlayer

  • HCMPC-HC
  • BEMPC-BE
  • KMKMPlayer
  • SMSMPlayer
  • mpvmpv
  • GOMGOM Player

Browsers work too: Chrome, Edge, Firefox, Brave, Opera and Vivaldi (on by default). A browser can't share the video position, so those cards show an elapsed timer instead of a progress bar.

Windows Media Player and the Windows 11 "Media Player" app don't put the film name in their window title, so they can't be detected.

04 / FAQ

Questions

Windows says "unrecognized app". Is it safe?

The exe isn't code-signed, so Windows SmartScreen shows a warning. Click More info → Run anyway. The whole project is open source, and you can read the code or build the exe yourself on GitHub.

Does it work with the Discord website or phone app?

It needs the Discord desktop app on the same PC as your player. The browser version can't receive Rich Presence from apps.

I can't see the "Get Media RPC" button on my own profile.

That's a Discord rule: Rich Presence buttons are only shown to other people. Ask a friend to check it.

What does it send over the internet?

Only the cleaned-up title (and year) is used to look up posters, and one request to GitHub checks for updates. With website detection on, only the title of a browser tab that is playing sound is read, and only to check whether it is a film or series. Turn on privacy mode and the film name is never shown on Discord. The app also sends a small anonymous usage count (a random install id and the app version, every 30 minutes) so the author can see how many people use it. It contains no film names and no personal data, and you can switch it off in Settings.

Is the download count real?

Yes. It is the total download count GitHub reports for MediaRPC.exe across all releases, fetched live when you open this page.
